# ระบบประกาศผลการออกรางวัลสลากกาชาดศรีสะเกษ ๒๕๗๐
> สลากกาชาด งานเทศกาลปีใหม่สี่เผ่าไทยศรีสะเกษ ประจำปี ๒๕๗๐  
> พัฒนาด้วย **Next.js (App Router)**, **Tailwind CSS**, และ **TypeScript**

---

## 🌟 จุดเด่นของระบบ (Features)

1. **หน้าบ้านสำหรับประชาชน (Public View)**:
   - แสดงรายการรางวัลตามเงื่อนไขสลากกาชาด ประจำปี ๒๕๗๐ ครบทั้ง ๑๒๗ รางวัล:
     - **รางวัลที่ ๑ (๒ รางวัล)**: รถยนต์โตโยต้าฟอร์จูนเนอร์ ๒.๔ LEADER G Plus
     - **รางวัลข้างเคียงรางวัลที่ ๑ (๔ รางวัล)**: ทองคำแท่งน้ำหนัก ๑ สลึง (เคียงคู่ขนาน ±๑)
     - **รางวัลที่ ๒ (๓ รางวัล)**: ทองคำแท่งน้ำหนัก ๑ บาท
     - **รางวัลที่ ๓ (๓ รางวัล)**: โทรศัพท์เคลื่อนที่ Apple iPhone 16 Pro
     - **รางวัลที่ ๔ (๕ รางวัล)**: รถจักรยานยนต์ Honda Wave
     - **รางวัลที่ ๕ (๑๐ รางวัล)**: ตู้เย็น ๒ ประตู ขนาด ๗ คิว
     - **รางวัลที่ ๖ (๑๐๐ รางวัล)**: เลขท้าย ๓ ตัว พัดลมตั้งพื้น ขนาด ๑๖ นิ้ว
   - **สถานะเริ่มต้น**: แสดงช่องว่าง `— — — — —` หรือรอผลรางวัล (ยังไม่ต้องใส่ตัวเลข)
   - **Auto-Refresh ทุกๆ ๕ วินาที**: มีแถบนับถอยหลัง 5s ดึงข้อมูลสดใหม่แบบเรียลไทม์โดยหน้าจอไม่กระตุก พร้อมปุ่มหยุดชั่วคราวและปุ่มรีเฟรชทันที
   - **ระบบตรวจผลสลากทันใจ**: กรอกเลข ๕ หลัก ตรวจสอบรางวัลทุกระดับทันที พร้อมเอฟเฟกต์จุดพลุ (Confetti) เมื่อถูกรางวัล
   - **พิมพ์ใบประกาศผลรางวัล (Print to PDF)**: จัดรูปแบบหน้ากระดาษอย่างเป็นทางการสำหรับปริ้นท์แจกจ่ายประชาชน

2. **ระบบสำหรับผู้ดูแลระบบ (Admin Only)**:
   - **สิทธิ์เฉพาะ Admin คนเดียว**: ล็อกอินผ่าน `/admin` ด้วยรหัสผ่านความปลอดภัยสูง (สุ่มรหัสผ่าน ๑๐ ตัวอักษรขึ้นไป)
   - **ฟังก์ชันอำนวยความสะดวก**:
     - กรอกหมายเลขรางวัลแต่ละช่องได้สะดวก
     - ปุ่ม **"คำนวณข้างเคียงอัตโนมัติ (±1)"** จากรางวัลที่ ๑
     - ปุ่ม **"สุ่มเลขทดสอบ (Test Mode)"** เพื่อทดสอบจำลองการออกรางวัล
     - ปุ่ม **"ล้างข้อมูลทั้งหมด (Reset to Empty)"** คืนค่าหน้าบ้านเป็นช่องว่าง
     - ระบบ **"สุ่มรหัสผ่านใหม่ (Random Password Generator)"** พร้อมปุ่มคัดลอก

## 🚀 วิธีการรันในเครื่อง (Local Development)

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. เริ่มต้นรันเซิร์ฟเวอร์
npm run dev
```

เปิดบราวเซอร์ที่:
- หน้าบ้าน: [http://localhost:3000](http://localhost:3000)
- หลังบ้าน (Admin): [http://localhost:3000/admin](http://localhost:3000/admin)

## 📦 วิธีการนำขึ้น GitHub และ Vercel

### ขั้นตอนที่ 1: อัปขึ้น GitHub

```bash
git add .
git commit -m "feat: initial commit for sisaket lottery announcement system"

# เชื่อมต่อกับ GitHub repository ของคุณ (สร้าง repo ใหม่บน GitHub ก่อน)
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
git branch -M main
git push -u origin main
```

### ขั้นตอนที่ 2: Deploy ขึ้น Vercel

1. เข้าไปที่ [vercel.com](https://vercel.com) แล้วล็อกอิน
2. คลิกปุ่ม **"Add New..."** -> **"Project"**
3. เลือก Repository จาก GitHub ที่เพิ่ง Push ขึ้นไป
4. ในส่วน **Environment Variables** ให้เพิ่มตัวแปรดังนี้:
   - `ADMIN_PASSWORD` = `<รหัสผ่าน Admin ของคุณอย่างน้อย 10 ตัวอักษร>`
   - `ADMIN_JWT_SECRET` = `ssk-lottery-secure-jwt-secret-key-99999-sisaket-2027`
   - *(ทางเลือกเสริม)* ถ้าต้องการ persistent database ข้าม serverless instance บน Vercel สามารถเชื่อมต่อ **Upstash Redis** ฟรีผ่าน Vercel Marketplace แล้วระบบจะ sync ข้อมูลให้อัตโนมัติทันที
5. คลิก **Deploy** แล้วรอประมาณ 1 นาที ระบบจะพร้อมใช้งานทันที!
